# Ledgerlight Roadmap

The spec ([2026-11-15-ledgerlight-design.md](../specs/2026-11-15-ledgerlight-design.md)) covers 15 stages across independent subsystems. Each group below gets its own detailed implementation plan, written just before it is executed, so that each plan can build on the real code (exact names, versions, Groq models of that week) instead of guesses. Every plan ends with working, deployed software.

| Plan | Stages (spec §13) | Ends with |
|---|---|---|
| **1. Foundation** — [plan](2026-11-15-plan-1-foundation.md) | 0 repo & agent setup · 1 infra + hello deploy · 2 auth & tenancy | Live URL serving a health check; tenant isolation proven by tests; agent rules and hooks active |
| 2. UI foundation | 3 design system & shell · 4 upload & inbox | Demo picker, app shell, inbox with real uploads (no AI yet) |
| 3. AI pipeline | 5 extraction | Real Groq extraction inside the free budget, receipts stored. **Re-check Groq models and free limits first.** |
| 4. Review | 6 review screen · 7 approval rules | Full review flow, auto-approve with guardrails |
| 5. Exports | 8 Tallyline & exports | Chaos mode, circuit breaker, dead-letter, recovery actions |
| 6. Proof | 9 AI audit · 10 synthetic invoices & evals | Receipt page, eval command, Quality dashboard, real seeded history |
| 7. Demo | 11 team settings · 12 demo mode | Private sandboxes, onboarding, team management |
| 8. Launch | 13 deploy hardening · 14 polish | README story, screenshots, docs, a11y/perf pass |

Commits go directly to `main`; each stage ends with an annotated tag `stage-NN` and an Outcome section in its mini-spec; Conventional Commits; no AI co-author trailers (enforced by the commit-msg hook from Plan 1).
